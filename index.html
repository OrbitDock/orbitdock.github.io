An overlay for your games, with the tools you already switch to built in.

Orbit is a game bar. Instead of alt-tabbing between a clipper, a screenshot tool and a chat app, you open one overlay on top of the game, do what you need, and close it again.

It is early. There is no release and no screenshot to show yet, and this page will be updated when there is.
